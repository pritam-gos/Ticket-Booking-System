# Train Ticket Booking CLI

A lightweight, menu-driven Python program that simulates a railway ticketing system in the terminal.

## Features

* **Book Tickets:** Input passenger details, route, train number, and select from 5 travel classes.
* **Check PNR Status:** Enter a 10-digit PNR and a waitlist number to get an estimated confirmation probability.
* **Cancel Tickets:** Enter your 4-digit booking ID, train number, and route details to simulate a cancellation.
* **Input Validation:** Enforces correct length for train numbers (5 digits), PNRs (10 digits), and booking IDs (4 digits).

## Prerequisites

* Python 3.x
* No external libraries required.

## How to Run

1. Save the code to a file named `main.py`.
2. Open your terminal or command prompt.
3. Run the script using the following command:
   
   ```bash
   python main.py
4. Run the script using the following command on Linux:
   
   ```bash
   python3 main.py
